Special replacements now drop the previous weapon on the same PCB side, using the existing pickup models and E interaction. A supported floor or component-top location must have player/model clearance and a clear collection path within 1.5 units. If replacement cannot place the old weapon safely, collection is refused. Invalid falling/death positions do not create a drop.

Drops retain ammo, reserve, heat, cooldown and an active reload deadline (including capacitor recharge). They expire after 30 seconds, never respawn, and lock out their previous owner for 0.75 seconds. Others may collect immediately. Map pickups retain the 15-second respawn. Drop metadata and all ownership transfers are server-owned; collection removes the pickup synchronously, so duplicate requests cannot claim it twice. Match resets remove drops and increment map pickup versions. Disconnects do not create extra drops.

Verification uses real multiplayer clients for replacement, peer collection, duplicate requests, preserved stock, sniper recharge transfer, expiry, and death drops, plus geometric placement checks. Manual check: collect a special, fire some ammo, replace it using E, then have another player collect the visible old weapon. Verify the magazine, swap Q, test owner collection after the short lockout, and leave an uncollected drop for 30 seconds.
